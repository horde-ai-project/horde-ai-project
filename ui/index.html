Start / stop

Process lifecycle stays on the host. Use the launcher scripts; the browser cannot start the binary.

  • scripts/horde-start.sh / horde-stop.sh (Unix)
  • scripts/horde-start.ps1 / horde-stop.ps1 (Windows)
  • Optional: horde-start.bat / horde-stop.bat

Copy .env.example → .env, set HORDE_PASSPHRASE, then start. Passphrase is never accepted over HTTP.

UI URL after start: http://127.0.0.1:8787/ui/

Mesh bind

Invite-bounded mesh listener (separate from the HTTP API bind). Changes apply at runtime — no process restart. Passphrase is never sent here.
